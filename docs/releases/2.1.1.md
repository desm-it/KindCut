# KindCut 2.1.1 — staged release notes

Status: locally prepared and staged; not tagged, committed, published or distribution-approved.

This maintenance update reorganizes project saving/loading, undo/redo, workspace rendering and native Make lifecycle ownership without intentionally changing user workflows or device protocol behavior. It adds typed RPC contracts, shared validation fixtures, discovered platform-aware tests, structural compiled-host import rewriting, pinned formatting and updated architecture documentation.

The accepted implementation passed the full repository checks, packaged macOS inert-runtime tests, isolated project-edit/save/load/preview checks and independent frontend/host reviews. See `../maintainability-refactor-results.md` for exact coverage and limitations. Those packaged application observations were on the pre-version-bump candidate; they are not a claim that a 2.1.1 installer has been published.

Native original-Joy support remains macOS-only in this release snapshot. Windows continues to use its existing legacy backend. Subsequent Windows-native work must remain outside this staged 2.1.1 snapshot until independently verified.

Known distribution and physical-device acceptance limitations are unchanged. No firmware, calibration, hardware motion or stock-performance certification is implied.
